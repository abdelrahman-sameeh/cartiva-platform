# أسلوب الردود

- الشرح والكلام يكون **بالعربي بالكامل**
- أي كود أو مصطلح تقني يتحط في `code block` منفصل
- متخلطش عربي وإنجليزي في نفس الجملة
- المصطلحات التقنية القصيرة (زي اسم متغير أو function) ممكن تكون inline code بس في سطر عربي

### مثال صح ✅

الدالة دي بتعمل يوزر جديد:

```php
$this->createUser();
```

### مثال غلط ❌

الـ `createUser()` function بتعمل create لـ new user في الـ database عن طريق الـ `User::create()` method.
